# Registry review input

Registry entries are immutable `(id, version, SHA-256)` pins. A configured host verifier validates release attestations and an explicit review before admitting a package. A self-declared verification flag never admits code. Promotions and rollback change only the active pointer; revocation blocks new jobs and approvals while existing uncertain cloud transactions remain reconciliation-only in the private transport.

No public registry is published by this checkout. Proposed repository names and the first export require owner review. Run the release audit before submitting a package; include compatibility evidence, full notices, exact source revision, input lock, artifact checksums and honest pending checks. Customer saves and account credentials are never submission assets.
