# Synthetic Frontier

This invented ASCII-framed JSON save demonstrates a connector with progression, factions, a vehicle and a camp. It is unrelated to Crimson Desert or Xbox. The separate `example.level-tools` package supplies level/XP/perk calculations and a complete custom progression graph through the public document API. Only this connector serializes the final file.

The wholly synthetic fixture is safe to redistribute. No Microsoft account, customer save, paid service or private module is needed. Run the SDK's conformance tests and local workbench against the exact manifest and runtime package digest.
