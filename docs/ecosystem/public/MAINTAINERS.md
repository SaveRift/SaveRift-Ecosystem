# Maintainers and release authority

This developer preview is prepared under the SaveRift project owner's
direction. The initial GitHub organization, repository owners, public
maintainers and private reporting contact have not been confirmed. Do not
infer them from a Microsoft gamertag or the private hosting origin.

Public source/export contents, repository destinations and the first release
require owner review. Registry admission, host deployment and live Xbox trials
are separately authorized decisions. Contributors retain their declared
copyrights and are credited in per-package notices and source history after
clean public repositories exist.
