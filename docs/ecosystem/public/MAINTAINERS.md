# Maintainers and release authority

This developer preview is prepared under the SaveRift project owner's
direction. Its canonical source repository is
[`SaveRift/SaveRift-Ecosystem`](https://github.com/SaveRift/SaveRift-Ecosystem),
currently private. Hosted game-project configuration names `ggrande` as a
maintainer. That label does not establish a contributor's linked identity,
GitHub App installation, repository permissions or release approval. Verify
those through the relevant authenticated service; never infer them from a
Microsoft gamertag or hosting origin.

Exact source/export contents and the first release audience require owner
review. Registry admission, host deployment and live Xbox trials are
separately authorized decisions. Contributors retain their declared
copyrights and attribution in per-package notices and source history.
Private repository access or a prerelease does not imply public availability.
