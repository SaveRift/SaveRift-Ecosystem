# Community conduct

Be respectful, concrete and welcoming in technical discussion. Critique code
and evidence; do not harass, threaten, discriminate against or expose private
information about contributors or players. Do not publish credentials or save
files belonging to others. Respect consent and licensing boundaries.

Maintainers may remove abusive material and restrict participation while
preserving a fair technical/dispute record. Report conduct privately through
the maintainer channel once public destinations are approved; until then use
the existing hosted Issues & Feedback summary path without personal data.
The public moderation team/contact is pending initial repository setup.
